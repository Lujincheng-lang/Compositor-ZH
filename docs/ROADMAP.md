# 继续接近 Photoshop 的开发顺序

目标是熟悉的专业操作与可靠结果。界面接近不等于渲染一致；完全兼容也不能通过外观测试证明。每阶段都以真实图片、实际文件和桌面交互验收。

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 0.1 当前基础版 | 中文桌面、栅格图层、画笔、矩形选区、文字、蒙版、基础调整、项目文件 | 实际启动、落笔撤销、项目重开、PNG/JPEG 与 PSD 程序回读 |
| 0.2 编辑与工作区 | 多文档、图层拖拽、组、多选变换、可停靠面板、参考线吸附、可配置快捷键、直接保存与另存区分 | 多文档之间复制、组内排序、取消拖动、快捷键冲突测试 |
| 0.3 选区与修图 | 椭圆选框、套索、多边形、选区加减交、羽化、魔棒、仿制图章、修复、选择与遮住 | 细发丝、半透明边缘和高反差轮廓样本；对比选区蒙版像素 |
| 0.4 非破坏编辑 | 可编辑矢量形状、钢笔路径、调整图层、曲线/色阶、剪贴蒙版、图层样式、智能对象 | 保存重开保持可编辑参数，变换不降源质量，复杂组合与历史验证 |
| 0.5 格式与输出 | 原版 .comp 完整语义、PSD 文本/组/蒙版/效果、JPEG 元数据扩展、ICC、16 位与 CMYK | 在真实 Photoshop 中打开/编辑/保存双向往返，色卡与色差评估 |
| 0.6 性能与正式发行 | 分块图层、GPU/WebGPU 合成、增量撤销、后台导出、故障恢复、签名安装器 | 4K/8K 文档、100+ 层、输入延迟、峰值内存与异常退出恢复 |

## 技术取舍

当前 Canvas2D 适合跑通编辑闭环，不能据此承诺 PS 的混合算法、色彩精度或 GPU 性能。后续逐步抽出 renderer、history、formats、tools 接口；采用分块像素和增量历史后再扩展大文件。保留 `.cwin` 作为无损原生项目，增加格式版本迁移测试，不为兼容其它格式悄悄丢弃高级结构。

下一阶段优先完成多文档、图层组与拖拽、套索和羽化。卡牌与图片合成场景再推进曲线、图层样式、剪贴蒙版与真实 PSD 往返。CMYK 与印刷输出应以专业实机色彩验证单独验收。
